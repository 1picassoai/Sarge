# Sarge

**Drills it until it sticks. Doesn't negotiate.**

A small local model writes your code. When it breaks a rule of your codebase, a tutor
teaches it that rule once, from its own mistake, and writes it into a book that lives with
the repo. From then on the rule rides at the tail of every turn, every file the model writes
is checked against it, and the run refuses while a rule is broken. Corrections that survive.

**The code lands here when it has passed our own tests, not before.** We are not selling
snake oil. Until then, one thing is open, and it is the reason this repo exists today:

## The board is open

**[Discussions →](../../discussions)** — a public suggestion box for the sloppy-agent problem.
Not a feedback form for Sarge. A place to put what your coding agent keeps getting wrong:
the rule it read and skipped, the correction you have typed three times this week, the
green build that shipped something useless. That is what Sarge gets built from, in the
open, for all of us.

- **Show and tell** — what your agent got wrong.
- **Ideas** — what Sarge should catch.
- **Polls** — which of these hurts most.
- **Q&A** — questions with an accepted answer.

No sign-up, no product pitch. Bring the problem.
